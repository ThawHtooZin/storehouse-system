# Plan-First Execution Skill

## Objective

[cite_start]Before modifying or adding a single line of code in this repository, you must generate a comprehensive implementation plan and pause for user approval.

## Plan Structure Requirements

Your plan response must strictly use this layout:

1. **Goal**: Short summary of what you are building.
2. **Database Impact**: List any migrations, new tables, or schema modifications required.
3. **Backend Alterations**: Specify exactly which Controllers, Models, or API Routes will be touched/created in `/backend`.
4. **Frontend Alterations**: Specify exactly which Components or Hooks will be created in `/frontend`.
5. **Potential Obstacles**: Highlight any breaking dependencies or data validation risks.

## Termination Gate

End your response with:
`"Waiting for your explicit confirmation to implement this plan, Sir."`
[cite_start]Do NOT generate any feature code until the user says "Approved."
